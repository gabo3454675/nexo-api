# nexo-api

API central de NEXO. Gestión de Escrow, servicios industriales, marketplace y seguridad multimoneda.

Backend en [NestJS](https://nestjs.com/) con Prisma.

## Requisitos

- Node.js (versión acorde a `package.json`)
- Variables de entorno: copia `.env.example` a `.env` y complétalas.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run start:dev
```

## Compilación y producción

```bash
npm run build
npm run start:prod
```

## Pruebas

```bash
npm run test
npm run test:e2e
npm run test:cov
```
